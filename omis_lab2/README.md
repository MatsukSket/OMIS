# CRM — лабораторная работа № 2 по ОМИС

В Windows откройте «Запустить CRM.cmd». Для запуска на другом компьютере установите Python 3.13, затем в PowerShell из каталога проекта выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m crm
```

При первом запуске создаётся рабочая база SQLite в `data/crm.sqlite3`. Она заполняется четырьмя компаниями, пятью сотрудниками, задачами, звонками и сделками относительно даты запуска. Отдельный файл `data/demo.sqlite3` содержит пример такого набора. Рабочая база сохраняет изменения при повторном открытии.

Введите любой непустой логин и пароль и выберите одну из трёх ролей. В учебном режиме кнопка открывает профиль первого активного сотрудника соответствующей роли. Логины и пароли не сохраняются.

1. Войдите менеджером. Найдите «Ромашку», откройте карточку, посмотрите сделки и звонки. Добавьте клиента и прикрепите файл.
2. Войдите руководителем. В списке видны клиенты отдела продаж. Откройте задачу, поменяйте исполнителя, срок или статус и проверьте уведомления.
3. Войдите администратором. В аналитике сформируйте недельный отчёт и экспортируйте его в Excel. В настройках создайте сотрудника.
4. Перезапустите приложение и проверьте созданные записи.

В карточке клиента на вкладке «Сделки» можно добавить, изменить или удалить сделку. Сумма указывается в целых BYN. Для открытой сделки оставьте флажок «Сделка закрыта» снятым. В отчёт попадают сделки с датой закрытия за выбранный период.

Задача — поручение сотруднику по клиенту со сроком, приоритетом и статусом. Например, «Отправить предложение к пятнице». Завершение задачи фиксирует выполнение поручения. Сделку закрывают отдельно в её форме.

Ролевые экраны используют общие компоненты PySide6. Отчёт рассчитывается синхронно по датам закрытия сделок. Строки отчёта показывают количество сделок, выручку и среднюю длительность по клиенту. Направления развития из CLASS_1–CLASS_3 в объём приложения не входят.
